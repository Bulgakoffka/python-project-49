## Minimal requirements:
* Python 3.12
* bash/zsh terminal that runs python scripts
* uv 0.6.3

## Games list:
* brain-even
* brain-calc
* brain-gcd
* brain-prime
* brain-progression

## Installation guide:
1. Clone the repository:
   
       git clone git@github.com:Bulgakoffka/python-project-49.git
   
3. Go to the project directory:

       cd brain-games
   
4. Install dependencies for project:

       uv sync
   
5. Install brain-games package
    
       make package-install
